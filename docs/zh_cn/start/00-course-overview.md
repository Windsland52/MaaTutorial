第一次接触 MaaFW 项目的人，面对一堆文件和字段，往往不知道从哪下手。本课程就是给你的新手教程，带你走通第一条路。官方文档则像字典，可以查阅具体的字段说明。两者相辅相成。

学完这套课程，你应该能：

- 看懂一个常规 MaaFW 项目的结构
- 知道常用工具分别解决什么问题
- 写出基本可维护的 Pipeline
- 把任务接入通用 GUI 做一次完整验证

## 适合谁

这套课程适合：

- 第一次接触 MaaFW，不知道从哪里开始的人
- 看过官方文档，但还没把项目跑起来的人
- 写过简单 MaaFW 任务，但没系统梳理过整体流程和调试方法的人
- 维护 MaaFW 应用项目，需要给新成员准备一份系统入门材料的人

如果你已经能独立维护复杂 Pipeline 和 Custom 扩展，那么这套课程对你来说偏基础。

## 你会学到什么

课程主线覆盖的内容，分成两条线：

**认知层面：**

- MaaFW 是什么，以及它和应用项目、通用 GUI、工具链之间的关系
- 一个 MaaFW 应用通常由哪些部分组成
- 什么时候需要 Custom

**动手层面：**

- 搭建本地开发与调试环境
- 编写并运行第一个任务
- 设计 Pipeline 节点与流程
- 用调试工具定位识别、动作和节点跳转的问题
- 编写 `interface.json` 接入通用 GUI
- 配置打包和分发流程，将项目分发给用户

::: tip
课程不会事无巨细地讲解每项工具。遇到 Git、GitHub 使用等课程没展开的基础概念，请善用 AI 辅助理解。
:::
